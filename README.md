# lihuu's Official Scoop Bucket

Official Scoop Bucket for Windows developer tools maintained by [@lihuu](https://github.com/lihuu).

## Available Manifests

| App | Description | Documentation |
| :--- | :--- | :--- |
| **`gpgkit`** | One command for the whole life of a GPG key | [Documentation](https://lihuu.github.io/li-tools/gpgkit) |
| **`certkit`** | Zero-dependency CLI for enterprise PKI and certificate management | [Documentation](https://lihuu.github.io/li-tools/certkit) |
| **`pasteex`** | Paste image or text as file from clipboard directly | [Repository](https://github.com/huiyadanli/PasteEx) |

## Quick Start

### 1. Add the Bucket
In PowerShell:
```powershell
scoop bucket add lihuu https://github.com/lihuu/my-scoop-bucket
```

### 2. Install Tools
```powershell
# Install gpgkit
scoop install gpgkit

# Install certkit
scoop install certkit
```

### 3. Update Tools
```powershell
scoop update
scoop update gpgkit certkit
```
